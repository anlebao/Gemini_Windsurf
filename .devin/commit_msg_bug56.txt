Bug 5: Order List + Kitchen gridview not rebuilding on SignalR/polling
- Root cause: OrderHub [Authorize] → SignalR negotiate returns 401 (Blazor Server
  client cannot pass auth cookie) → real-time updates broken
- Fix: Replace [Authorize] with [AllowAnonymous] on OrderHub (internal hub,
  only broadcasts events from OrderSyncSubscriber via IHubContext)
- Also: Add explicit StateHasChanged() after diff check in Index.razor +
  Kitchen/Display.razor (safety net for poll timer edge cases)

Bug 6: Loyalty points not awarded for completed orders
- Root cause: ProcessLoyaltyPointsAsync only looked up customer by CustomerId.
  All 77 completed orders had CustomerId=NULL (guest checkout) → customer not
  found → points skipped. CustomerDeviceId was set but never used for lookup.
- Fix: Add DeviceId fallback lookup + Customer stub creation from DeviceId +
  Order.CustomerInfo when neither CustomerId nor DeviceId finds an existing
  customer. This allows loyalty points to be awarded for all completed orders.
