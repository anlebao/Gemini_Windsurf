fix: SubtractPointsAsync nested transaction crash on redeem (SQLite)

RedemptionService.RedeemAsync begins an outer transaction, then calls
LoyaltyRewardsService.SubtractPointsAsync which also called
BeginTransactionAsync → SQLite throws "The connection is already in a
transaction and cannot participate in another transaction."

AddPointsAsync was already fixed for this same bug (Bug 6) but
SubtractPointsAsync was missed. Applied the same pattern: remove the
explicit BeginTransactionAsync and rely on the caller's ambient
transaction (or auto-commit if no ambient transaction exists).
