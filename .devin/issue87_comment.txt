Fixed in commit defdabf3.

Root cause: Gateway serializes CommerceMode enum as int (default System.Text.Json behavior), but ShopERP client expects string. JSON deserialization fails: "The JSON value could not be converted to System.String. Path: $.globalMode".

Fix: Add JsonStringEnumConverter to Gateway Program.cs AddJsonOptions. Now all enums (CommerceMode, OrderStatus, etc.) serialize as strings.
